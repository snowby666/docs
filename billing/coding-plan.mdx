The **Coding Plan** (DevPass) is a flat-rate plan for coding agents and CLIs — Claude Code, Cursor, Cline, Roo Code, and any OpenAI- or Anthropic-compatible client.

You get a dedicated `ek-dev-` key, a curated `:dev` model list, and **unlimited tokens with no credit burn, subject to [fair use](#fair-use)**: usage is not capped by a token allowance, but speed and concurrency are limited. It does not replace a subscription or pay-as-you-go balance; it stacks with them.

## Tiers

| | **Lite** | **Turbo** |
|---|---|---|
| Price | **$10**/month | **$40**/month |
| Concurrent slots | 2 | 6 |
| Request starts / min | 8 (burst 4) | 20 (burst 8) |
| Queue when busy | Standard | Priority |
| Full-speed headroom | Baseline | **6×** Lite |

Token usage is not capped on either tier, subject to [fair use](#fair-use). Past full-speed headroom you stay online in a slower lane (see [Limits](#limits)) — you are never cut off for burning tokens.

<Warning>
  Seats are capped per tier. If a tier is sold out, join the waitlist on the dashboard. Openings are first come, first served.
</Warning>

## Quickstart

1. Subscribe at [Dashboard](https://app.electronhub.ai) → **Console** → **Coding Plan**.
2. Copy the `ek-dev-...` key from that tab (regen invalidates the old key immediately).
3. Call the API:

```bash
curl -X POST "https://api.electronhub.ai/v1/chat/completions" \
  -H "Authorization: Bearer ek-dev-YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-5.3:dev",
    "messages": [{"role": "user", "content": "Refactor this function..."}],
    "stream": true
  }'
```

## Limits

These controls keep the pool usable. None of them are a hard token cap.

### Concurrent slots

| Series | Slots / request | Lite (2) | Turbo (6) |
|---|---|---|---|
| Flash · Standard | 1 | 2 at once | 6 at once |
| Heavy (`glm-5.3:dev`) | 3 | **Blocked** (`403`) | 2 Heavy |

A request holds its slots until it finishes. If it needs more slots than are free → `429` with `Retry-After`.

In the slow lane, concurrency drops to **1** on Lite and **2** on Turbo. Heavy needs 3 slots, so it is refused with `403` / `model_slots_exceeded` until the healthy cap returns. Flash and Standard still run. On Lite, Heavy is never available — upgrade to Turbo for `glm-5.3:dev`.

### Full-speed headroom

| Window | Size | Resets |
|---|---|---|
| Daily | Soft budget (Turbo = 6× Lite) | Every day at **21:00 UTC** |
| Weekly | **5×** the daily budget | **Sunday 21:00 UTC** (fixed week, not rolling) |

Past either budget you keep running, but admission slows: concurrency drops (Lite → 1, Turbo → 2), RPM shrinks, and inter-request spacing grows with consumption (up to ~30s when far over). The dashboard meters show remaining headroom. Series weight applies to these budgets; see [Models](#models).

### Requests per minute

Continuous refill: **8/min** Lite (burst 4), **20/min** Turbo (burst 8). Every start counts once, including Heavy. Slow lane: **3/min** (burst 2).

Over the limit → `429` with `Retry-After`. Headers: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`. These RPM `429`s do **not** count toward the concurrency pause below.

### Concurrency pause

About **100** concurrency `429`s in a usage day can pause admission for **5 hours**. Paused requests return `403`. The key remains valid; service resumes at the dashboard time. Regenerating the key clears an automatic pause.

### Low-interactivity mode

If usage looks far beyond one person coding, the seat may enter this mode for ~**24 hours**:

- Light load: unchanged.
- Busy periods: may queue behind interactive traffic; retry if needed.
- Models, quality, and entitlement stay the same. Not a suspension.

It clears automatically at the time on the Coding Plan tab. If it surprises you, check for runaway automation first, then ask on [Discord](https://discord.com/invite/electronhub).

## Fair use

**One person, one seat.** Lite and Turbo are alternatives, not stackable — upgrade instead of buying twice.

You may use the key on machines you personally use (home, work, laptop, CI, VPN). All of that counts as the same seat.

**Suspended for:** second seats under identities you control; sharing the key; pooling seats for throughput; resale or access-as-a-service; backends that serve other people; unattended multi-user production traffic.

**Payment disputes:** a payment dispute or chargeback suspends or closes the whole account, including the `ek-dev-` key. Please contact support before disputing a charge.

High-duty-cycle or multi-user traffic belongs on a credit-billed master key.

To enforce fair use we keep short samples of recent requests per `ek-dev-` key (up to 20), plus request timing and network data, as described in the [Privacy Policy](https://tos.electronhub.ai/privacy#content).

## Errors

| Status | Cause | What to do |
|---|---|---|
| `429` | No free slots, or RPM budget empty | Honor `Retry-After` |
| `403` `model_slots_exceeded` | Heavy needs 3 slots; current cap is below 3 (Lite always, or Turbo slow lane) | Use Flash/Standard, or upgrade to Turbo / wait for the slow lane to end |
| `403` | Concurrency pause | Wait for the dashboard resume time, or regen the key |
| `403` | Suspended / ended / fair-use enforcement | Fix payment, resubscribe, or contact support |
| `404` | Model not on the Coding Plan list | Pick a `:dev` id from [Models](#models) |

## FAQ

<AccordionGroup>
  <Accordion title="Is usage really unlimited?">
    Tokens are not capped and there is no per-token charge, subject to fair use: speed, concurrency and priority are not unlimited. Soft headroom slows concurrency, RPM, and spacing when you are far past typical interactive use, and the plan is for one person's own use (see [Fair use](#fair-use)).
  </Accordion>
  <Accordion title="Can I hold two seats?">
    No. One person, one seat. Upgrade to Turbo for more parallel slots.
  </Accordion>
  <Accordion title="What happens when the subscription ends?">
    The `ek-dev-` key is deactivated. Resubscribe to restore it.
  </Accordion>
  <Accordion title="Why can’t Lite run glm-5.3:dev?">
    Heavy uses 3 concurrent slots. Lite has 2, so admission refuses it with `model_slots_exceeded`. Upgrade to Turbo (6 slots) to run Heavy.
  </Accordion>
</AccordionGroup>
