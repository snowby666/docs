Anthropic-style message creation at `POST /v1/messages`. Compatible with Anthropic SDKs and Claude Code (`ANTHROPIC_BASE_URL=https://api.electronhub.ai`).

## Create Message

`POST /v1/messages`

### Request Body

<ParamField body="model" type="string" required>
  Model ID (for example `claude-sonnet-4-5-20250929`, or Coding Plan models like `kimi-k2.6:dev`)
</ParamField>

<ParamField body="messages" type="array" required>
  Conversation turns. Roles: `user`, `assistant`, or mid-conversation `system`.
</ParamField>

<ParamField body="max_tokens" type="integer">
  Maximum tokens to generate
</ParamField>

<ParamField body="system" type="string | array">
  Top-level system prompt. Prefer an array of text blocks when using prompt caching or Claude Code.
</ParamField>

<ParamField body="thinking" type="object">
  Extended thinking config: `{ "type": "enabled", "budget_tokens": N }`, `{ "type": "adaptive" }`, or `{ "type": "disabled" }`. Optional `display`: `"summarized"` or `"omitted"`.
</ParamField>

<ParamField body="tools" type="array">
  Tool definitions (`name`, `description`, `input_schema`). Built-in Anthropic tool `type` values are accepted. Optional: `strict`, `defer_loading`, `eager_input_streaming`.
</ParamField>

<ParamField body="tool_choice" type="object">
  `{ "type": "auto" | "any" | "tool" | "none" }`
</ParamField>

<ParamField body="temperature" type="number">
  Sampling temperature
</ParamField>

<ParamField body="stream" type="boolean">
  Stream SSE events when `true`
</ParamField>

Optional Claude Code / gateway fields are accepted and ignored by non-Anthropic upstreams: `betas`, `context_management`, `output_config`, `metadata`.

### Content blocks

| Role | Supported `content` block types |
|---|---|
| `user` / `system` | `text`, `image` (base64 or url), `document`, `tool_result`, `mid_conv_system`, `tool_addition`, `tool_removal`, plus passthrough server-tool result types |
| `assistant` | `text`, `tool_use`, `server_tool_use`, `thinking` (with `signature`), `redacted_thinking` |

Multi-turn clients (including Claude Code) must echo prior assistant `thinking` / `redacted_thinking` blocks unchanged.

### Auth

`Authorization: Bearer <api_key>` or `x-api-key: <api_key>`.

### Response

Anthropic message object (`id`, `role`, `content`, `stop_reason`, `usage`). Errors use `{"type":"error","error":{...}}`.

### Example

<CodeGroup>

```javascript Node.js
const response = await fetch('https://api.electronhub.ai/v1/messages', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    model: 'claude-sonnet-4-5-20250929',
    max_tokens: 1000,
    messages: [
      { role: 'user', content: 'Hello!' }
    ]
  })
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.post(
    'https://api.electronhub.ai/v1/messages',
    headers={
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json'
    },
    json={
        'model': 'claude-sonnet-4-5-20250929',
        'max_tokens': 1000,
        'messages': [
            {'role': 'user', 'content': 'Hello!'}
        ]
    }
)

print(response.json())
```

```bash cURL
curl -X POST "https://api.electronhub.ai/v1/messages" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "claude-sonnet-4-5-20250929",
    "max_tokens": 1000,
    "messages": [
      {"role": "user", "content": "Hello!"}
    ]
  }'
```

## Count Tokens

`POST /v1/messages/count_tokens`

Estimates input tokens for a Messages-shaped payload (same body fields as create). Returns `{ "input_tokens": number }`. Used by Claude Code when available; otherwise Claude Code estimates locally.
