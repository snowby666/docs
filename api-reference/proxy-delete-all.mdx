---
title: "Delete All Proxy Keys"
api: "DELETE https://api.electronhub.ai/v1/auth/proxy/delete"
description: "Delete all proxy keys for the authenticated user"
openapi: "DELETE /auth/proxy/delete"
---

Deletes every proxy key on the account. Irreversible.

<RequestExample>

```bash cURL
curl -X DELETE https://api.electronhub.ai/v1/auth/proxy/delete \
  -H "Authorization: Bearer $ELECTRONHUB_API_KEY"
```

```python Python
import httpx

response = httpx.delete(
    "https://api.electronhub.ai/v1/auth/proxy/delete",
    headers={"Authorization": f"Bearer {api_key}"},
)

result = response.json()
print(f"Bulk delete result: {result['message']}")
```

```javascript Node.js
const response = await fetch('https://api.electronhub.ai/v1/auth/proxy/delete', {
  method: 'DELETE',
  headers: {
    'Authorization': `Bearer ${process.env.ELECTRONHUB_API_KEY}`,
  },
});

const result = await response.json();
console.log(`Bulk delete result: ${result.message}`);
```

</RequestExample>
